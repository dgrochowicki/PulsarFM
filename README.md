# Pulsar FM

W kosmosie nie ma dźwięku, więc go robimy.

Muzyka generatywna i wizualizacja grane na żywo z danych o pogodzie kosmicznej (NOAA: wiatr słoneczny, pole magnetyczne, Kp, rozbłyski) i z pulsarów. Mapa nieba działa jak radio: każdy pulsar to stacja z własnym gatunkiem, a jego prawdziwy rytm wyznacza tempo albo tonację.

Uruchomienie: otwórz `index.html` przez serwer HTTP (np. `python3 -m http.server`) albo przez GitHub Pages. Kliknij „Posłuchaj”.

Jak powstaje dźwięk (synteza, instrumenty w każdym gatunku, co zmieniają dane): [docs/DZWIEK.md](docs/DZWIEK.md).

Szczegóły projektu, mapowanie danych i plan: [CLAUDE.md](CLAUDE.md).
